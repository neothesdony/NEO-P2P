# 02 — Prompt Terjemahan

**Sumber:** manual/USER_MANUAL.md (EN)
**Target:** Bahasa Indonesia — audiens umum Indonesia, gaya storytelling (mengalir, ramah) dengan kejelasan manual.

## Aturan
- Tulis ulang, bukan terjemahan kata-per-kata: hasil harus terbaca seperti ditulis asli oleh penutur bahasa Indonesia.
- Akurasi penuh: angka, biaya, status, batas waktu, alamat contoh — persis seperti sumber.
- Pertahankan format markdown (heading, bold, tabel, blockquote, kode).
- Token status escrow (FUNDING, FUNDED, SIGNED, PAYMENT_PENDING, RECEIPT_SENT, CONFIRMING, RELEASED, CANCELLED, REFUNDED, DISPUTED, RESOLVING, MATCHED, OPEN, PAUSED) tetap EN kapital — itu label yang tampil di aplikasi.
- Label tombol UI: tulis label EN asli, lalu terjemahan ID dalam kurung (mis. **Create Offer** (Buat Penawaran)).
- Istilah teknis (escrow, multisig, mainnet, E2EE, TOFU, UTXO, BI-FAST, RTGS, QRIS, kode unik, Tolak Bukti, HAPUS) dipertahankan; tambahkan penjelasan singkat hanya jika perlu.
- Desimal Indonesia: 0,5% (koma). Rupiah: Rp 5.000.000.
- Peringatan (⚠️, bold) dipertahankan kekuatannya.

## Glosarium
frasa seed, escrow, multisig 2-of-3, penawaran, biaya, dompet, payout, gerbang pelepasan, rekan, sidik jari, kode unik, masa berlaku, rekening dibekukan, bukti transfer palsu, sengketa, arbiter, refund, setoran, kedaluwarsa, kecocokan (match), umpan (feed), tarik untuk menyegarkan, kunci layar, izin notifikasi, deep link, tanda tangan, disiarkan (broadcast).

## Struktur
16 bagian + header versi/platform/jaringan. Pertahankan penomoran §.
